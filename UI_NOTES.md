# GeoAI panel: UI changes

| Area | Before | Now |
|---|---|---|
| Text size | 9-11px labels | 12-14px, 17px key figures |
| Loading | button text only | skeleton cards while analysing, spinner on the button |
| Errors | red text box | what went wrong + "Try again" button |
| Empty state | one grey paragraph | what you will get + colour key for the three pin types |
| Result header | name + small text | LGA name, area, "Exposure rank 7 of 30" badge (rank 1 = most exposed) |
| Key figures | 4 small boxes | 4 boxes with colour for High/Moderate + one stacked bar of the area split |
| Data gaps | not mentioned | note under the facilities table: a zero can mean missing data |
| Actions | 4 equal buttons | grouped: "Report and data" (primary: Briefing report) and "Print and share" (posters) |
| Ranking | plain table | sticky header, bar in the index column, current LGA highlighted, keyboard rows |
| 30-poster ZIP | text message | progress bar and a Stop button |
| CSV check | small dashed button | drop zone (click or drag a file), file type check |
| Choropleth | checkbox | switch plus a Lower-to-Higher colour ramp |
| Panel | fixed | collapse button, Esc closes, sits above the mobile bottom bar on phones |
| Accessibility | none | tab roles, labelled controls, focus rings, live status messages, 44px+ touch targets on mobile, reduced motion |
